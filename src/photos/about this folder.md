This folder holds the Obsidian notes that publish to the portfolio website via Enveloppe.

Folders:
1. `Feed` publishes writing and updates to `/feed/`
2. `Projects` publishes project write-ups to `/projects/`
3. `Photos` publishes photo gallery entries to `/photos/`

Publishing is controlled by frontmatter. Notes without `share: true` are never published.
